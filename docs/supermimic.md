## 1. 需求规格（2026-11-05 确认）

| 需求 | 验收门 |
|---|---|
| 不倾斜 | 横滚：所有地形 P95 ≤5°、最大 ≤8°。<br>俯仰：平地 P95 ≤5°，≤12 cm 单台阶 ≤8°；楼梯上跟随坡度，P95 ≤ 坡度−5°、最大 ≤ 坡度+3°。<br>俯仰角速度 RMS：平地 ≤8°/s，楼梯 ≤15°/s。 |
| 提前抬轮 | **单台阶**（10、14、17.5 cm，分全宽、左窄、右窄）：一次只抬一个轮。至少一个前轮在立面前 3–12 cm 处离地 ≥5 mm 且 Fz≤1 N，保持到沿口，落轮后通过；同一根轴的另一个轮可以接触立面后滚上去。每档至少 64 回合，成功率 ≥70%。<br>**单台阶和楼梯**都要求轻碰快上：接触立面前的速度 P95 ≤0.15 m/s，贴住立面的时长 P95 ≤0.5 s（物理原因见 §1.1）。 |
| 高楼梯 | 立面 8、12、16、17.5 cm，踏面 0.40 m 和 0.28 m 各一组。每档至少 64 回合，严格通过率 ≥70%。 |
| 平稳 | 摆臂速度 RMS：平地 ≤0.4 rad/s，台阶/楼梯 ≤0.8 rad/s。所有统计都是跨环境取 P95，不用中位数。 |
| 平地行驶 | 偏航 P95 ≤10°，横移 P95 ≤0.15 m，速度 RMSE ≤0.08。 |

几何约束如下：轮半径 0.1085 m，摆臂 0.20 m（±35°），轴距 0.694 m。

- 在 17.5/28 cm 的楼梯上，车身俯仰最小约 12–20°，不可能保持水平，所以楼梯上的俯仰门按坡度相对值来定。

### 1.1 预抬的物理边界（2026-11-06，按 URDF 正运动学与质量计算）

| 动作 | 能否做到 | 依据 |
|---|---|---|
| 两前轮（或两后轮）同时离地 | 不能 | 只剩一条轴支撑，任何摆臂角下质心都在后轴前 ≥27.5 cm；靠加速翘头需要摩擦系数 ≥1.3 |
| 单轮离地、三轮支撑 | 能，但裕度很小 | 四轮矩形的质心落在对角线上：只动被抬轮的摆臂时裕度约 0。要靠其余摆臂把车身倾斜约 3° 先移质心。横滚 ≤5°、俯仰 ≤8° 时最佳裕度约 2.2 cm，这些姿态中约 40% 能有 ≥0.5 cm；横滚 10° 时最佳约 4.4 cm |
| 单侧（窄）台阶预抬 | 能 | 前轮、后轮先后各抬一次，每次三轮支撑 |
| 整宽单台阶预抬 | 每根轴一个轮 | 同轴两轮同时到达立面，不能都离地。一个轮先抬起、搭上台面（另外三个轮撑住），同轴另一个轮接触立面后滚上去；后轴同样。另一种做法是斜着过，让四个轮依次到达，但需要车身斜约 21°，没有采用 |
| 楼梯每级四个轮都预抬 | 不能 | 一个轮离地越过立面至少要走一个轮半径（10.85 cm），四个轮每级共需 ≥43 cm 的单轮悬空行程，但踏面只有 26–30 cm，而同一时刻只能有一个轮离地 |
| 楼梯每级前轴一个轮预抬 | 能 | 只要求前轴一个轮，每级约 11 cm 悬空行程。车头抬起后质心后移，前轮单轮离地的三轮支撑裕度比平地更大。后轮单抬时质心在支撑三角形外，只能轻碰后靠立面托住翻上去 |
| 楼梯后轴两轮同时顶住立面翻上去 | 看摩擦，直行很难 | 车头抬起后后轴载荷更大，只有两前轮的摩擦力往上推。物理探针（脚本控制器，摆臂中立、停住时轮端打满）：8 cm 直行需 μ≥0.86，12 cm 在 μ≤1.2 内都上不去；训练和验收的轮动摩擦在 0.4–1.0 随机 |
| 楼梯斜着上（车身偏 12°） | 能，摩擦要求低得多 | 两后轮先后碰立面，一个翻的时候另外三个轮一起推：8 cm 降到 μ≥0.6，12 cm 降到 μ≥0.86。4WS 蟹行保持沿路线前进 |

结论：
- 单台阶上：每根轴一个轮先抬，另一个轮轻碰后滚上去（2026-11-06 与用户确认）；
- 楼梯上：前轴每级一个轮先抬（2026-11-07 起），后轴轻碰快上；车身斜 12° 上楼梯，让同轴两轮先后碰立面（2026-11-07 第六轮起）；
- 上一版的立面接近代价（−500）在整宽立面上罚不掉，只能靠把车身歪过去抬单轮来减少，这正是第二轮训练中台阶横滚 17–19° 的来源。

## 2. 方法

### 2.1 基础设计（第一到十三轮定型）

下面是第十三轮时的写法，后来改过的数值以 §2.2 和 `run_train.sh` 为准。已知的变化有：

- 楼梯区航向目标 12° → 6°；
- 整宽单台阶也斜行 6°；
- 楼梯晋级的横偏门一直是 0.40 m，不收紧；
- 轻碰代价 −200 → −400，楼梯上 ×0.5；
- 领先前轮预抬 `--prelift_front 25`。

**优化规模**（对齐上游 SuperMimic，以及历史最好的 scratch_40k_r8k）：
- 想象 4096 条 × 32 步；
- actor 学习率从 1e-4 余弦衰减到 1e-5，每轮都更新；
- 价值梯度 ×1.0，GAE λ=0.95；
- 世界模型用 8 步窗口 × 2048 × 10 次更新；
- 动作噪声 0.1；
- 左右镜像增强，镜像一致性损失系数 0.1。

**目标函数**（8 组，互不重叠，全部在 `preview_task.py` 里）：
1. 速度跟踪，立面前 0.30 m 内允许减速到 min(cmd, 0.12 m/s)（轻碰需要），另有进度奖励和停滞惩罚（−5，须重于越障途中的代价）；
2. 终止惩罚 −20，倾角超过 0.8 rad 终止；
3. 姿态：横滚全程罚，超过 4.5° 后另加 −2000·(|g_y| − sin4.5°)²（10° 时约 −18/步）；俯仰按"θ_ref ±3°"罚，θ_ref = sign(θ_geo)·max(|θ_geo| − 6°, 0)，θ_geo 为前后轮下地形的几何俯仰（摆臂能补偿约 0.2 m 高差），不再有平地/障碍的硬切换；
4. 平稳：角速度、摆臂速度、动作变化率、竖直速度，全程生效；
5. 直行：偏航（sin²ψ −30 加 sinψ 的 Huber −5，小偏航也有梯度；楼梯区——任一轮前方 0.60 m 内有非单台阶立面——目标改为 |ψ|=12°，左右任取）、偏航角速度（−2·ω_z²）、横移速度（Huber，δ=0.02 m/s，系数 15）、转向；车道惩罚 −30·y² 用训练特权横向偏移（与 critic 的车道特征同源），actor 仍为 232 维、看不到车道；
6. 平地承重和摆臂回中；
7. **越障**（按 §1.1 的物理边界设计，四个轮同一公式，几何每个状态只算一次）：
   - 预抬/翻越净空跟踪（5.0）：单台阶的所有轮、以及任何立面（含楼梯每级）前的前轴，在立面前 0.12 m 内要求离地，对齐验收的 3–12 cm；接触后（轮廓到达立面）对所有立面跟踪翻越所需的净空。每根轴一次只要求一个轮：同轴两轮都在跟踪（窗口内或翻越中）时取两轮误差的较小者，一个轮先抬/先翻，另一个等它上去后单独面对立面再翻；窄台阶上面对立面的轮必须抬。误差取两种净空的平均：实际净空（轮底到轮下地面），和支撑净空（假设其余三轮落在各自地形上时这个轮的净空 = 自身净空减去三轮间隙在该轮位置的仿射外推）。支撑净空对车身平移和小角度倾斜不变，梯度只经摆臂，不依赖世界模型对车身的预测；
   - 三轮支撑裕度（−10）：质心投影到支撑三角形的裕度不足 0.5 cm 时罚。计入的轮有两类：一是离地轮（轮廓-地形间隙 >1.2 cm）；二是预抬窗口内该抬的轮，不论它抬没抬（同轴两轮只计一个，窄台阶计面对立面的轮）。这样策略要先倾斜车体移质心再抬轮，不抬也逃不掉这项代价。立面上正在翻越的轮（立面角托住）、刚越过下行边沿正在落下的轮（下台阶）不计。两轮同时悬空另罚 −5·(n−1)²，这两类轮同样不计；
   - 轻碰（−200）：着地轮距立面 <5 cm 时，前进速度超过 0.15 m/s 的部分按平方罚；
   - 准备行程（−1）：立面前 0.30 m 内，摆臂剩余上抬行程不足"立面高度 + 1 cm"时罚；
   - 早抬（−2）：只用在单台阶上，立面前 >0.12 m 离地时罚，缩短三轮支撑时间；
8. 关节限位，软限位系数 0.95。

**地形与课程**（`tasks/.../supermimic/obstacle_terrain.py`、`obstacle_env_cfg.py`）：
- 楼梯立面 4→20 cm，踏面在 0.26–0.40 m 之间随机；单台阶 3→20 cm，分全宽、左窄、右窄。
- 比例：楼梯 45%，单台阶 40%，平地 15%。
- 每种地形单独计课程等级。前进 ≥3.6 m 且 |y| ≤0.15 m、姿态超限 ≤5% 才升级；单台阶另要求碰立面步数 ≤10%（零碰撞只作为验收标准），楼梯不设碰撞门；翻车、出车道（|y| >0.40 m）或前进不到期望距离的一半（含停滞）就降级；到顶级后随机回落。
- 回合 40 s。x ≥3.6 m 时回合必然结束：|y| ≤0.15 m 为成功截断，否则按出车道终止（楼梯顶端平台在块边是断崖，不能继续开）。
- 命令只在本任务里改：前进 0.10–0.40 m/s，约 10% 静止命令。父类的阈值命令会把 ≤0.2 m/s 的命令清零，所以本任务换成 Isaac Lab 的 `UniformVelocityCommand`。
- 日志按地形类型记录等级和等效高度（cm），另记 `lateral_abs_m`（车道横偏）。

**已删除**：
- PPO 热启动；监督/BC 初始化和动作参考；全部锚定；
- 探索脉冲；平地校准采样；
- 三版旧预抬目标、准备势函数、idle_lift、prelift_settle；
- actor 的车道真值输入（只作为 critic 的特权输入和训练奖励保留）；
- 上一版的流水线、修复和诊断脚本，以及对应的旧文档和日志。

**提速**（2048 env 实测，每轮 9.3 s → 1.33 s）：
- `_reward_gap` 等诊断项只在记日志的那一轮计算；
- 正运动学改用 Rodrigues 形式并预乘缓冲，误差 ≤1.2e-7；
- 世界模型单步用 `torch.compile` 编译，射线投射函数排除在编译之外；
- 观测核对改为每 500 轮做一次。

想象步编译后，曾在台阶状态上反传出 NaN，所以原先默认关闭，并带自动回退；2026-11-07 再次实测仍出 NaN，继续默认关闭（见 `docs/supermimic_history.md` 第七轮之后的"想象单步编译"）。

### 2.3 训练是确定性的

同一个种子、同样的参数，从零训练的结果逐位相同：第二十轮前 2.2 万轮和第十八轮的存档 sha256 一样，验收也一样。由此有两点：

- 只在训练后期才起作用的改动，从零重跑时前面那一段只是重放旧的训练；
- 要比较“同一配方的另一次结果”，必须换种子。

现在各轮都固定用种子 42，便于对照。

## 3. 使用

```bash
# 训练（nohup + setsid 后台；默认 2048 env × 40000 轮，每 1000 轮存档）
bash scripts/supermimic/run_train.sh <run_name> 2048 40000
tail -f logs/supermimic_terrain/<run_name>.log
# 续训（同名 run 的最新存档，日志追加；训练进程还在时拒绝启动）
RESUME=1 bash scripts/supermimic/run_train.sh <run_name> 2048 40000
# 热启动：从另一个 SuperMimic run 的存档接着训（learner 状态、课程等级、轮数沿用；日志/存档写到新 run；奖励按新参数）
FROM_RUN=<旧 run> FROM_CKPT=ckpt_020000.pt bash scripts/supermimic/run_train.sh <新 run> 2048 40000
# 改了奖励的热启动：warmup / critic 预热 / 学习率衰减从载入轮数重新起算（总轮数含旧存档已跑的）
FROM_RUN=<旧 run> FROM_CKPT=ckpt_020000.pt bash scripts/supermimic/run_train.sh <新 run> 2048 36000 \
  --warm_start_reset --critic_warmup_iterations 300 --actor_lr 5e-5 --actor_lr_decay_iterations 14000
# 打磨阶段：课程冻结、小学习率恒定
FROM_RUN=<run> FROM_CKPT=ckpt_0XX000.pt bash scripts/supermimic/run_train.sh <新 run> 2048 <载入轮数+5000> \
  --warm_start_reset --curriculum_freeze 1 --actor_lr 1e-5 --actor_lr_final 1e-5

# 导出中间存档（带 actor_ema 时默认导出 EMA 权重，--raw 导出原始 actor）
python scripts/supermimic/export_ckpt.py --load_run <run_name> --iterations 20000

# 训练中的过程验收：每 2000 轮对新存档跑一次 rotate 验收（低优先级，同一时间只跑一个 Isaac 评测）
nohup bash scripts/supermimic/watch_accept.sh <run_name> 2000 > logs/supermimic_terrain/<run_name>_watch.log 2>&1 &

# 最终验收（留出种子 9001/9002/9003，约 50–55 分钟）
python scripts/supermimic/accept.py --load_run <run_name> --iteration 40000

# 诊断：单独评测一个楼梯档位（--supermimic_terrain 下默认用固定摩擦 μ=1.0，--wheel_friction 可覆盖）
python scripts/reinforcement_learning/rsl_rl/evaluate_parallelogram_vision.py --headless --policy teacher-preview \
  --supermimic_terrain --checkpoint <policy.pt> --scenario pyramid_stairs_inv --num_envs 64 --episodes_per_env 1 \
  --seed 142 --acceptance_metrics --output <out.json> --difficulty 0.0 --stair_riser_m 0.08 --stair_tread_m 0.40 \
  --wheel_friction 1.2 1.0
```

热启动的命令保留在上面，但从第二十轮起，比较实力只用从零训练的结果（你 11-14 的要求：热启动不代表真实水平）。

## 4. 风险和待办

- **等你决定的需求项**：
  1. 接触前 ≤0.15 m/s、单台阶贴面 ≤0.5 s、横滚最大 ≤8° 是不是实车的硬要求。
     - 静态可行性（第十四轮）：第二个前轮和后轴，在横滚 ≤8° 内只能碰到立面再翻，不能先抬空再放上去；
     - 历轮的接触前速度都在 0.35–0.7 m/s。
  2. 踏面 28 cm × 立面 16–17.5 cm 的楼梯要不要留在需求里。要留的话，课程的踏面规则也得改。
- **楼梯横偏**：actor 看不到横向位置，只能靠航向和同相转向来保持车道。r27 到 3.6 万轮才学会同相反打，之后又丢了。r28 去掉偏离终止，并加“车轮行进方向对准路线”的代价，见 §0.1 表里的 r28 方案。部署接口固定 232 维，不加横偏输入。
- **接触前速度的口径**：验收取每次贴面前 5 步内车体 x 速度的最大值，四个轮、反复贴面都算；训练罚的是立面 5 cm 内的前进速度。两者可能不一致，例如前轮翻上去以后车体前冲，后轮撞上下一级。要先在验收里逐次记下是哪个轮、第几级、多大速度。
- **车头低**：r18 第 1.6 万轮平地静止俯仰约 7°。第十二轮也出现过，当时的原因是前摆臂动作饱和。r18 是不是同一个原因还没核对；要以 r18 的配方为起点，得先查这一点。
- **三轮支撑裕度很小**：静稳定裕度最多约 2.2 cm，门槛 0.5 cm。实机受扰时，抬起的轮可能落回去（不会翻车）。
- **价值梯度**：critic 对平地姿态的估值起伏 5–20，远大于 32 步内的奖励差约 1.5。策略在少见状态（平地静止、低速）上容易被 critic 的噪声带偏。
- **权重是按量级估的**：支撑裕度、净空跟踪、轻碰、横滚超限、车道、镜像这几项。
- **θ_ref 扣了 6°**：12 cm 单台阶的几何俯仰约 9.8°，扣完约 3.8°。楼梯上 θ_ref 比坡度低 6°。
- **URDF 左右有 4–8 mm 不对称**，镜像增强只是近似。
- **执行器要核对**：仿真里摆臂刚度 20 N·m/rad、力矩上限 10 N·m，要确认实机摆臂是否一样软。
- **深度学生**（`train_scan_student.py`）：等越障教师过门以后，再按 232 维教师重新适配并蒸馏。
- **已解决**：
  - 轮胎摩擦：第十轮起固定 μ=1.0；
  - 按验收几何录视频：现在用 `eval_video.py`（由 `mk_video27.py` 生成），`play.py` 仍然只能回放旧的预览地形。
